## 二、游戏引擎

**我们现在的做法**：一个网页文件，画面、动画、点击、摆放全部是手写代码。一开始做小 demo 这样最快，但后来要接你画的素材、做专业的特效、做装扮系统，手写的方式就成了瓶颈：每个物件的位置要我一个个量像素，每个特效要从头写，加一种新素材要改很多处代码。这个问题我应该在你开始交美术素材的时候就提出来。

**引擎能直接给的东西**：图层和前后遮挡、精灵和帧动画、补间动画（弹跳、飞行、淡入淡出）、粒子特效、镜头拖动缩放、资源加载和图集、场景切换、点击检测。装扮系统在引擎里就是「把这个物件的贴图换一张」。

| 引擎 | 适合 | 优点 | 缺点 |
|---|---|---|---|
| **Phaser**（网页 2D 引擎） | 只自己用；我写代码、你出图 | 还是网页，手机直接打开、能离线、能装到桌面；现在的发音、离线识别、存档、内容都能原样搬过去；我能在云端写代码、自动测试和截图 | 没有免费的可视化编辑器，摆放物件靠我们在游戏里做「摆放模式」 |
| **Cocos Creator** | 以后要发微信小游戏、安卓、苹果 | 国内最常用的 2D 引擎；有可视化编辑器，物件可以直接拖；一套代码能出多个平台 | 编辑器要装在你的电脑上，我在云端打不开，很多操作要你自己点；离线语音识别要重新接 |
| Godot | 想自己动手学做游戏 | 免费开源，编辑器好用 | 网页版体积大，手机浏览器里接录音和离线识别比较麻烦 |
| Unity | 大型 3D 或商业项目 | 功能最全 | 对我们太重，网页版很大 |

**我的建议**：只给自己用 → **Phaser**；以后要上微信或应用商店 → **Cocos Creator**，而且现在就换，越晚换代价越大。

**怎么换（以 Phaser 为例）**：先只搬农场（底图分层、装扮系统、种植收获特效），厨房、小馆暂时保留原样；农场稳定了再一页页搬。发音、识别、存档、单词内容、色卡都直接沿用，存档不会丢。
