# 豆豆的田园厨房（像素风手机游戏 demo）

种菜、用英语口语做菜，再用英语接待客人。整个游戏就是一个文件 `index.html`，不用安装，也不用构建。

## 玩法循环

1. **农场**：点地块就能播种、捉虫、除草、浇水、收获、清理枯苗。虫子、杂草和缺水都会拖慢生长。母鸡每 75 秒下一个蛋。收获时会弹出一句英文让你跟读，说得好可以多拿 1～2 个作物。
2. **厨房**：8 道菜，按等级解锁。每一步都是一句英文做法（Wash the lettuce. / Crack two eggs into a bowl. …），说完后豆豆会把这一步做出来。每步平均星级决定这道菜是几星，星级越高售价越高。
3. **小馆**：小动物客人用英语点菜、问价，你要用英语回答和报价（价格数字每次不同）。两句都说到三星还有小费。
4. **词本**：食材、动作动词、做菜句子、待客句子都收在这里，带音标和每条的最佳成绩。「快速练习 ×5」会优先抽你说得最差的几条。

另外还有每日任务、升级解锁新作物和新菜、开垦新地。农场的天色跟着手机的真实时间变化。

## 口语怎么打分

- 「听」和「慢速」用浏览器自带的英文朗读。
- 「说」用浏览器的语音识别（Web Speech API）。识别结果和目标句逐词比对，比对时会忽略大小写、标点、缩写（it's = it is）和阿拉伯数字（32 = thirty two），单复数算接近。每个词会标绿、黄或红，85 分以上三星，60 分以上两星。
- 没有麦克风或浏览器不支持识别时，会自动改成「听 → 跟读 → 自评」。设置里也可以手动切换。

注意：Chrome 的语音识别要联网，音频会发给浏览器厂商的识别服务。Safari 用的是系统的听写功能。

## 在手机上打开

语音识别需要 HTTPS 页面，下面任选一种：

- **直接打开**（这个仓库是公开的）：
  `https://raw.githack.com/a01022971718-cyber/mv/ccr-17470247-hlo7zp/game/index.html`
  raw.githack 是第三方服务，会把 GitHub 上的文件按网页转发出来。
- **GitHub Pages**：仓库 Settings → Pages → 选这个分支，然后打开 `…/game/index.html`。
- **claude.ai 上的 Artifact 版本**：可以直接玩，存档会同步到你的 Claude 账号，但在那里面拿不到麦克风，只能跟读自评。

打开后在浏览器菜单里点「添加到主屏幕」，就能像 App 一样全屏打开。

## 存档

存档在浏览器的 localStorage 里（键名 `doudou-farm-kitchen-v1`），换浏览器或清除网站数据会丢失。设置里可以重新开始。

## 改内容

全部数据都在 `index.html` 的「游戏数据」一节：`CROPS`（作物、生长秒数、收获句）、`RECIPES`（菜谱和每一步的英文）、`T_ORDER` / `T_REPLY` / `T_ASK` / `T_PRICE` / `T_THANKS`（小馆对话模板）。新增一步做菜时，`act` 决定厨房里播放哪个动画（wash / cut / peel / tear / scoop / mix / crack / mash / heat / fry / boil / blend / pour / season / bake / serve）。

所有像素画都是代码逐像素画出来的（没有图片文件），角色豆豆沿用仓库里 `sheet/tofu.js` 的原创豆腐角色。
