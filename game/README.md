# 豆豆的田园厨房（像素风手机游戏 demo）

种菜、用英语口语做菜，再用英语接待客人。网页游戏，不用安装，第一次联网打开后可以离线玩。

## 玩法循环

1. **农场**：16 块地（能自己挪、加、藏，见下面「自由摆放」），一开始开好 6 块，其余升级后花金币开垦。点空地选一次种子，之后点别的空地就连着种同一种（底部有播种条，点「完成」结束）；种子沿弧线落进土里，小苗弹出来。熟了头顶出现「⭐可收」，收获时果实弹起、冒星星、飞进仓库，收完地直接变回空土。点地块还能捉虫、除草、浇水。地块头顶的气泡告诉你该做什么。虫子、杂草和缺水都会拖慢生长。母鸡每 75 秒下一个蛋。收获时会弹出一句英文让你跟读，说得好可以多拿 1～2 个作物。
2. **厨房**：8 道菜，按等级解锁。每一步都是一句英文做法（Wash the lettuce. / Crack two eggs into a bowl. …），说完后豆豆会把这一步做出来。每步平均星级决定这道菜是几星，星级越高售价越高。
3. **小馆**：小动物客人用英语点菜、问价，你要用英语回答和报价（价格数字每次不同）。两句都说到三星还有小费。
4. **词本**：食材、动作动词、做菜句子、待客句子都收在这里，带音标和每条的最佳成绩。「快速练习 ×5」会优先抽你说得最差的几条。

## 两种玩法

设置最上面可以切换：
- **学习模式**（默认）：收菜要跟读，做菜每一步、上菜每一句都要说出来，系统打分；星级决定菜价和小费。
- **游戏模式**：收菜、做菜、上菜都不用开口。英文照样显示、照样读给你听；做菜点「做这一步」就做（算两星），上菜点「下一句」往下走。想练的时候点「开口说」，说好了多拿星星和小费。离线识别的开通卡和评分设置在这个模式下收起来。

## 我们自己的记忆点

- **会说英语的蔬菜**：8 种作物各有独特的轮廓和主色（圆红番茄、尖橙胡萝卜、疙瘩土豆、紫洋葱、高个玉米、褶边生菜、心形草莓、扁圆南瓜）。成熟后长出小脸，表情来自它的英文收获句：番茄 *red and ripe* 会脸红，洋葱 *Onions make me cry!* 会流泪，土豆 *Dig up the potatoes* 埋在土里打瞌睡，南瓜 *What a big pumpkin!* 一脸得意。成熟的菜还会轮流冒出气泡喊自己的英文名。
- **作者原画的两种作物**：精灵芽 *sprout*（Lv2）和蓝铃花 *bluebell*（Lv4），种子店能买，长大和成熟时直接显示作者画的图。收获句：*The sprout is smiling at me!* / *Listen! The bluebell is singing.*
- **点哪儿学哪儿**：农场里的房子、稻草人、喷泉、信箱（放了装扮时）、远处的小屋 cottage、小山坡 hill、小路 path、灌木丛 bush、云 cloud、海、山、栅栏、花、母鸡、窝都能点，点一下弹出英文名牌并读出来。左上角「标签」按钮一次显示所有名牌。这些词也收在词本的「场景」分类里。
- **住在作物里的四只精灵**：Sprig 小芽、Bud 苞苞、Sunny 阳阳住在精灵芽里，Swirl 旋旋住在蓝铃花里。还没熟的精灵芽、蓝铃花点一下，精灵会用自己的声音说一句英文（下面跟中文），每次换一句；12 句台词也收在词本的「精灵」分类里，可以跟读练习。
- **农场画面**：底图是作者交的干净底图（`art/src/farm-clean-ai.jpg`，去掉了稻草人、房子、喷泉、信箱），`tools/bg_prepare.py` 补好右边接缝、拼出「没开垦」版（草格菜地取自原画）、整体提亮，得到 `art/farm.webp`（没开垦）和 `art/farm-open.webp`（开垦版里菜地那一块）。哪块地开垦了，就从开垦版里按这块地的形状裁出来盖上去。稻草人、房子、喷泉、信箱都是装扮，单独画在上面。

图比手机屏幕宽，在农场上左右拖动就能看到右边的蛋糕屋、喷泉和蘑菇信箱；还能往哪边拖，画面边上就有小箭头提示。豆豆在菜地下面的沙土路上走，母鸡和鸡窝在菜地左下的草地上（这两样还是代码画的，等美术素材，见 `ART.md`）。

## 自由摆放和界面编辑（第 27 版）

- **菜地**（装扮 → 编辑菜地，或开发者模式 → 菜地）：下面有两种编辑方式。
  - **整块菜地**：拖四个黄点对齐菜地的四个角；拖中间的白点，整块菜地一起挪。
  - **单块地**：地上标着第几块。点一块选中，拖它挪到任何地方，拖四个蓝点改形状；「＋ 加一块地」在屏幕中间加一块（第 17、18……块），「藏起来」把不要的地藏掉（虚线框点一下能放回来），加的地可以「删掉」；选中的地可以改开垦要多少金币、几级以后。点「完成」才存，「全部还原」回到原来的 16 块。
  - 开垦后的土跟着地走：挪过的、加的地，会把原画里那块地的土「搬」过去，变成新的形状。单块改过的地记在「原来那块菜地」的坐标里，所以之后再拖整块菜地的四个角，它们也跟着走。每张底图的菜地分开记。
- **物件转向和前后**（装扮 → 调整位置和大小）：除了拖动、放大缩小，还有左转、右转（每次 15°）、翻转（左右镜像）、往前、往后（图层 −5 到 +5：每往前一层，相当于脚底往下挪 40 像素，排到更前面）。点转过的物件照样能点中。地图场景里的物件也一样：编辑 → 点物件 → ↺ ↻ ⇋ 往前 往后。
- **豆豆点哪走哪**：在农场点空地，豆豆走过去；点地、物件、母鸡、可点的东西，豆豆也走到旁边。按脚底排前后，能走到房子、树后面。闲着时在附近溜达。场景里也有「我」：点哪走哪。能走的范围是 `DD_AREA`（湖、远山和天空上去不了）。
- **界面**（开发者模式 → 界面）：配色先选一套（原样、薄荷、樱花、夜色、海洋），再单独改某个颜色（大背景、面板、按钮、字……一共 14 个）；方角（像素风）或圆角；格子背景或纯色背景；底部标签、种子店、仓库、一键收获、标签、装扮按钮上的字和游戏名字都能改；底部标签的顺序能调。存在游戏设计里，导出的客户端也带上。

## 开发者模式和导出客户端（第 25 版）

设置 → 开发者模式（工具箱里也有入口）。这里是「做游戏」的地方，平时玩的是它做出来的游戏。

- **内容总表**（`REG`）：每类内容写一份字段说明，开发者模式就自动生成「列表 + 新加 + 修改 + 删除 / 还原」的界面。现在有：
  - **作物**：新加一种（中文、英文、长大的图、几级解锁、种子价、生长时间、一次收几个、卖价、经验、收获时说的话）；自带的也能改数字和名字、还原、或者不在种子店卖。新作物自动进种子店、能种能收、进仓库和词本、语音包自动生成发音、口语识别自动认得、装扮里自动多一个作物装扮位。
  - **装扮位**：新加一个（比如游泳池），再到装扮里上传图片、拖到想放的地方。
  - **菜谱**（第 26 版）：新加一道菜——中文和英文菜名、客人点菜时的说法、菜的图（可以不传，会画一个盘子）、几级解锁、卖价、要哪些食材（从作物和鸡蛋里选，几个）、每一步做法（英文、中文、厨房动画的动作、用哪样食材）。新菜自动进厨房，小馆客人会点它，每一步的句子进词本、语音自动生成；新加时送一份食材马上能试做。自带的菜能改名字、价格、几级解锁，或者先不做。
  - **小馆客人**（第 26 版）：新加一位——英文名字、中文、传一张图（不传就用小猫/小兔/小熊/小鸭/浣熊造型加你选的毛色和衣服颜色）、声音（10 种男声女声）。客人说的话用他自己的声音。自带的客人也能改，或者先不来。
  - **小馆对话**（第 26 版）：五类——客人点菜（用 `{p}` 代表菜名）、你上菜、客人问价、你报价（用 `{n}` 代表价钱）、客人道谢。每类都能加新说法、改自带的、或者不用，每次随机挑一句。
- **有自己编辑器的**：主题/底图/装扮、菜地、界面、可点的东西、地图/场景/地点、玩法（工具箱）、分级课程、我加的单词，开发者模式里一键跳过去。
- **还不能改的（排队中）**：植物精灵、豆豆说的话、任务种类、成就种类、风格卡。
- **漏登记检查**（`CONTENT_TABLES` + `tests/dev.js`）：测试会扫代码里所有大写名字的表，新出现的内容表没登记（能改 / 有编辑器 / 排队中），测试就不通过——防止又出现「写死了、玩家改不了」。
- **功能开关**（`FEATURES`）：厨房、小馆、学习页、地图、装扮、工具箱、标签、每日任务、成就、备份、语音包、背景音乐、开发者模式，每个都能关。
- **导出客户端**：起名字、换图标 → 「发布成 App」（要在云备份里填的 GitHub 令牌多勾 `public_repo`）。游戏把设计、素材、功能开关写进仓库 `game/apps/<名字>/`，1–2 分钟后打开给出的链接，「添加到主屏幕」就是一个新图标。客户端用 `index.html?app=<名字>` 打开，存档、图片仓库都和开发版分开。也可以「下载客户端包」存成文件。
- **安卓安装包**：每次发新版，完整游戏的安装包自动重打（`apk-dev`）；发布客户端后，GitHub Actions（`.github/workflows/apk.yml` + `tools/build_apk.sh`，用 Capacitor）自动打成 `.apk`，放到仓库的 Releases（标签 `apk-<名字>`），大约 10 分钟；完整游戏的安装包标签是 `apk-dev`。安装包里有游戏、图片、自带录音和离线识别模型；生成语音的大模型用到时从网站下载。

## 分级学习（第 24 版）

底部「学习」页（原来的词本在下面）。

- **5 个等级**：1 启蒙（动物、蔬果、颜色、数字）→ 2 入门（打招呼、家人、天气、农场干活）→ 3 初级（厨房、买东西、时间、心情）→ 4 中级（描述、过去的事、问路、餐馆）→ 5 高级（计划、想法、讲故事、待客）。每级 4 课，每课 8 个单词 + 4–5 句话。内容在 `index.html` 的 `UNITS`，只写英文和中文，语音由语音包生成。
- **选级**：第一次进来自己选从哪一级开始；低的等级随时可以回去学。
- **考试**：每级 12 题（听音选词、看中文选英文、开口说；没开麦克风时换成选择题），**考到 80 分**升到下一级并得金币；没考过会列出错的题，随时再考。考过 5 级 **毕业**，发毕业证（写自己的名字）。
- **自己加课**：「＋ 自己加一课」，每行写「英文 = 中文」，自动生成语音、加进口语识别词表。
- **复习**：每说一句就按遗忘曲线排下次复习时间（说得好隔得久，说得差几小时后再练），「今日复习」把到期的拿出来练。

## 目标和奖励

- **每日任务**：多了「练分级课程」「复习」「在玩法里收获」（有对应内容时才会出现）。
- **成就**（`ACHV`）：收获、开口说、三星、做菜、待客、连续打卡、每级考试、毕业、自己加课、复习、做玩法、换主题、备份……共 27 个，大多带金币奖励。「学习 → 成就」查看。
- **连续打卡**：哪天开口说过英语就算一天，显示在今日任务和学习页上。

## 美术体检和风格卡

- 上传装扮、作物、图标、底图、地图时自动体检：尺寸够不够、背景去没去掉、有没有贴边、暗的地方是不是太多、细节是不是太碎、颜色离色卡远不远、底图是不是 16:9。**只提醒、不改图**，有问题弹出大白话建议。
- **风格卡**（`STYLE_CARDS`）：场景物件、作物、主题底图、地图、图标五种，每种有规格和可以直接复制给 AI 出图工具的中文 / 英文提示词。入口：装扮窗口「怎么画？」、体检报告、工具箱「风格卡」。

## 备份

- **本机快照**：每天自动存一份进度；重新开始、导入、恢复之前也先存一份。设置 → 本机快照 → 恢复。
- **备份到手机文件**：一个文件里有进度 + 全部上传的素材，存到手机文件或网盘；换手机时「从文件恢复」。一周没备份会提醒一次。
- **云备份（可选）**：设置 → 云备份 → 按步骤在 GitHub 生成一个只有 gist 权限的令牌，粘贴一次；之后有改动自动备份到你自己的私密 Gist（隐藏页面时、每 30 分钟检查，距上次超过 1 小时才传）。换手机填同一个令牌，点「从云端恢复」。

## 工具箱（第 23 版）

状态栏的工具箱按钮（红色小箱子）。思路：**常用功能都做成模板，你选模板、传图、填英文，新玩法就做出来了，不用写代码**。

- **玩法模板**（`MOD_TPL`）：
  - **养成**：放进去 → 等它长大 → 收获。牧场、果园、养鱼塘都用它。每样东西填：图片、中文、英文、收获时说的一句英文、要多久、花多少金币、得多少金币。
  - **钓鱼 / 采集**：点「开始」，指针走到绿色区域时点「收」，按稀有度随机抓到一样，弹出卡片、读英文。池塘、捉虫、采蘑菇都用它。
  - 做法：工具箱 → ＋ 新玩法 → 选模板 → 起名字 → 放到潮流街区的哪个地点（或新加一个）→ 进去点「编辑」换底图、加东西、选特效和音乐。地图上点那个地点就能进去，头像会跟过去。每个玩法有自己的图鉴。
- **特效**（`FX_PRESETS`）：星星、爱心、彩纸、泡泡、叶子、金币。玩法收获时用哪个自己选；农场收获也能换。
- **背景音乐**（`BGM_GEN`）：自带 3 首程序合成的小曲（田园、夜晚、欢快），也能上传音乐；农场、地图、玩法各用各的，音量三档。说英语录音时自动暂停。默认关着，在工具箱里打开。
- **音效**：点按钮、点东西、金币、收获、升级、失败，每种都能换成上传的声音，也能还原。
- **外观**：直达装扮/主题/底图、可点的东西、地图编辑。
- **语音包**：见下面。

工具箱里没有的新类型玩法（比如要有新规则的小游戏），由我按 `.claude/skills/doudou-module` 加一个模板；加一次，以后想做几个就做几个。

## 可复用的系统（第 22 版）

做游戏最费时间的是「每次换东西都重做一遍」。所以游戏里能换的东西都做成了系统：放进素材 → 自动处理 → 直接能用，不用再改代码、也不用等我重新生成。

| 系统 | 在游戏里怎么用 | 自动做了什么 |
|---|---|---|
| **语音包** | 写文案（或在游戏里填英文）就行 | 游戏把所有英文当作「文案清单」，没语音的由手机上的发音引擎在后台一条条生成（客人、精灵用各自的声音），存在手机里。连 Wi-Fi 时自动下载语音包（约 120MB，只下一次），也可以在设置或工具箱里点下载；第一次遇到没语音的句子会问一次。以后加内容不用再做发音包 |
| **主题和底图** | 装扮 → 底图 → ＋ 上传底图；存成主题 | 铺满成 2048×1152；只有开垦版时，没开垦的地自动压暗；主题记住底图 + 全部装扮 + 位置 |
| **菜地** | 装扮 → 编辑菜地：整块拖四个角，或者一块块挪、改形状、加、藏 | 地按四个角整体透视变形；挪过的、加的地把原画里的土搬过去 |
| **可点的东西** | 装扮 → 可点的东西，框出来、填英文和中文 | 点了弹名牌、读英文、有波纹；英文自动收进词本 |
| **地图和场景** | 地图右上角「编辑」 | 见下面「地图」 |
| **我加的单词** | 词本 → 我加的 → ＋ 加单词；或者在上面任何地方填英文 | 进词本、自动生成发音、加进口语识别词表 |
| **课程** | 学习 → ＋ 自己加一课 | 语音、识别词表、复习时间全自动 |
| **字体** | 随便输入中文名字 | 游戏里常用的字已经内联；没有的字按需加载完整像素字体（`vendor/fonts/`，600KB，只在用到时下载） |
| **素材包** | 设置 → 导出 / 导入素材包 | 装扮、底图、地图图片、名字、主题、我加的单词打包成一个文件，换手机导回来 |

我这边（程序）也固定成了流程：`game/tests/run.sh` 一条命令跑完全部自动测试；`.claude/skills/` 里有三个技能——发布新版本（`doudou-release`）、重做发音（`doudou-voice`）、美术素材入库（`doudou-art-intake`），以后每次都按同一套步骤做。

## 装扮

农场左上角的「装扮」按钮打开装扮窗口。稻草人、房子、喷泉、信箱和每种作物各有一个装扮位，点一下就换上，存档会记住。
- **默认**：稻草人是圣诞稻草人，房子是万圣节树屋；喷泉、信箱默认空着，等上传。场景物件都可以选「不放」。
- **装扮位**：稻草人、绿树、粉树、广告牌、房子、喷泉、信箱，10 种作物，还有地图上的「我的头像」。
- **自带的装扮**：圣诞稻草人、万圣节树屋、南瓜精灵（南瓜长大和成熟时的样子）。
- **上传自己画的图**：在装扮位后面点「＋ 上传」，从手机里选一张图。游戏会自动处理：白底图去背景、去掉 AI 抠图留下的半透明淡雾、裁掉四周空白、按装扮位的大小等比缩小、按色卡校色。上传的装扮存在这台手机的浏览器里（IndexedDB），断网也能用，换手机要重新上传；点缩略图右上角的 × 删除。
- **调整位置和大小**：装扮窗口里点「调整位置和大小」，回到农场用手指拖动物件，下面的按钮放大、缩小、左转、右转、翻转、往前、往后、还原，点「完成」记住（每个装扮分开记）。点物件时按图里不透明的地方判断，透明的空隙点下去算点到后面的东西。

**主题**：装扮窗口最上面一行。一个主题就是一整套装扮（每个位置用哪个、摆在哪、多大），一点全换上。自带「节日」（圣诞稻草人 + 万圣节树屋）和「空地」；「＋ 存成主题」把现在的样子存下来，可以改名、删掉。上传的装扮名字也能改（点 ✎）。

加新的装扮位：在 `index.html` 的 `SKIN_SLOTS` 里加一行（`anchor` 是脚底中点、`box` 是最大宽高，都按农场原画的像素；`def` 是默认装扮）。自带装扮放在 `art/skins/`（用 `tools/skin_prep.py` 处理），在 `SKINS` 里登记。规格见 `ART.md`。

## 地图

两层：**世界地图**（`art/map/world.webp`，美术交的像素版，原来画在潮流街区上的小头像去掉了）→ 点「潮流街区」进**小地图**（`art/map/trend.webp`，从截图里裁出来，去掉了按钮和原来的字）→ 点「我的农场」回到现在玩的农场。世界地图上 38 个地名、潮流街区 11 个地名是游戏叠上去的字，可以改。

- **点地点**：第一下有反馈（地点弹一下、发光、一圈波纹、音效），底下显示名字和能不能进；再点一次或点「进去 / 打开」就进去。画在底图里的建筑，会把那一圈底图拿出来放大再弹回，看起来像建筑自己在弹。
- **我在哪**：豆豆头像（装扮里「我的头像」可以换成自己的图）显示在你所在的地点。在农场时，世界地图上它在潮流街区，小地图上在我的农场；进了自己加的场景，头像就跟到那个地点。
- **编辑**（右上角）：拖动地点挪位置；点一下地点改名字、小字、英文（填了点它时会读出来）、换图标和大小、设置通向哪里（不通 / 小地图 / 场景）、藏起来或删掉；底下可以「＋ 加地点」、换这张图的底图、改这张图的名字、用回原图、找回藏起来的地点。
- **加场景**：给一个地点选「小地图」或「场景」，再选一张底图，就加好了。小地图里又能加地点（可以一层层往下做）；场景里能「＋ 加东西」，上传图标、起名字、填英文，点它会弹一下、显示名字、读英文。
- 改的名字、位置存在存档里；上传的底图和图标存在这台手机的浏览器里（IndexedDB 的 `imgs`），换手机要重新上传。

数据在 `index.html` 的 `BOARDS`（自带的地图）和 `PLACES`（自带的地点，坐标按原图像素）；玩家改的都在 `S.cfg.mapx`。

## 示范发音

- **玩家自己加的英文**（地图地点、场景里的东西、可点的东西、我加的单词）：用手机里的发音引擎现场生成（`vendor/kokoro/`：kokoro-js + onnxruntime-web，q8 模型 92MB，在后台线程里跑，画面不卡；生成一个词约 3–8 秒，存进 IndexedDB 的 `voice`，以后秒放）。引擎没下载时先用手机自带朗读。
- 所有句子和单词都用开源神经网络语音 [Kokoro](https://huggingface.co/hexgrad/Kokoro-82M) 预先合成成录音，打包在 `voice.js` 里（740 条，标准美式发音），不依赖手机自带的朗读，也不需要联网。
- 每句话有两种播放：**原速**（自然语速）和**逐词**（一个词一个词读，正在读的词会高亮）。句子里的任何一个词也可以直接点着听。
- 示范句用同一个女声（af_heart）。五位客人各有自己的声音，听力练习时能听到不同的人说话。
- 生成后用 Vosk 把每条句子反向听写了一遍，整体词错误率 2.6%，剩下的错误基本是识别模型自己的同音混淆（pour/poor、coins/kinds）。检查中发现 Kokoro 把做菜用的 tear（撕，/ter/）读成了 tear（眼泪，/tɪr/），已经用音标强制改正。单读的 a 用弱读 /ə/，和句子里一致。

## 离线口语识别

- 用 [Vosk](https://alphacephei.com/vosk/) 英文小模型，在浏览器里以 WebAssembly 运行（`vendor/vosk.js`），录音不出手机。
- 第一次打开时，农场页有一张「开启离线口语评分」卡片：点「开启」会请求麦克风权限并下载约 40MB 的模型，显示真实的下载百分比。模型下载后由识别库存进浏览器的 IndexedDB，之后断网也能用。也可以以后在口语卡或设置里再开。
- 录音时麦克风键里有实时音量条；说完停顿约 1.5 秒自动结束，显示「识别中…」。说完可以点「听我的」回放自己的录音，和示范对比。
- 两种识别模式（设置里切换）：
  - **宽松**（默认）：只在游戏里出现过的句子和单词里找，听不清的词记作「？」。口音重一些也能认出来。
  - **严格**：不限词表，发音不准的词会被认成别的词，更能暴露发音问题。
- 打分：识别结果和目标句逐词比对，忽略大小写、标点、缩写（it's = it is）和阿拉伯数字（32 = thirty two），单复数算接近，识别置信度低的词也只算接近。每个词标绿、黄或红，85 分以上三星，60 分以上两星。
- 说明：这是「说的词对不对、清不清楚」的检查，不是逐个音素的专业发音评测。
- 拿不到麦克风时（比如在 claude.ai 里打开），自动改成「听 → 跟读 → 自评」。

麦克风需要 HTTPS 页面：

  （raw.githack 是第三方服务，把这个公开仓库的文件按网页转发出来。）
- **GitHub Pages**：仓库 Settings → Pages → 选这个分支，然后打开 `…/game/index.html`。如果想连模型也自己托管，把 `vosk-model-small-en-us-0.15.tar.gz` 放到 `game/vosk/` 下再提交（这个目录默认被 .gitignore 忽略）。

打开后在浏览器菜单里点「添加到主屏幕」/「安装应用」，就能像 App 一样全屏打开。离线用的前提是：联网打开过一次（缓存游戏和发音包），并在游戏里下载过一次识别模型。

### 更新和存档

- **一个地址 = 一份游戏 + 一份存档**。进度存在那个地址的浏览器存储里：同一个地址更新后进度保留；换了地址（比如 claude.ai 里的版本、另一个托管地址）就是另一份，进度不通用。claude.ai 上的 Artifact 版本是单独的一份（进度同步到 Claude 账号），不是手机上那个图标的更新渠道。
- **自动检查更新**：联网打开时，游戏去 GitHub 看最新版本号（`version.json`），比自己新就弹窗「有新版本」，点「现在更新」只换游戏本身，进度、金币、单词成绩都保留。设置 →「版本」里也能手动「检查更新」。
- **raw.githack 的缓存**：它的分支地址有时会把旧文件缓存好几个小时，所以在 githack 上更新时，游戏会跳到最新提交的固定地址（`raw.githack.com/…/<提交号>/game/index.html`，和图标是同一个网站，进度共用）。GitHub Pages 没有这个问题，更适合长期当 App 用。
- **存档码**：设置 →「复制存档码」把整份进度变成一串 `DOUDOU1.` 开头的文字；到另一个地址或另一台手机，设置 →「粘贴存档码」就能把进度搬过去。
- **发布新版本时**：想让已经装好的手机弹出「有新版本」，就把 `index.html` 里的 `BUILD` 加一、`version.json` 里的 `build` 同步改（小修小补可以不加，下次打开会悄悄换上）；动了缓存的文件还要把 `sw.js` 的 `V` 加一。玩家点了「以后再说」，这一版就不再自动弹，设置里仍能手动更新。
- **安装成 App**：清单文件叫 `manifest.json`。raw.githack 会把 `.webmanifest` 和图片重定向到 raw.githubusercontent（另一个网站），浏览器会因此提示「无法安装此应用」；`.json` 它会直接转发，没有这个问题。githack 的固定提交地址（用来更新的那个）故意不提供安装，免得装出第二个图标。

## 美术与界面规范

- **引擎**：农场画面用 [Phaser](https://phaser.io) 3.90（Canvas 渲染）画：底图、开垦的地、装扮物件、作物、角色、特效、气泡名牌都是场景对象，按脚底位置排前后；拖动画面就是移动镜头。游戏逻辑、点击判定、厨房、小馆、地图还是原来的代码，以后一页页搬进引擎。
- **像素单位**：农场底图按 384 CSS 像素高显示（原图 3 像素 = 1 CSS 像素，3 倍屏手机上正好一一对应）；叠在上面的画布是 1 个美术像素 = 1 个 CSS 像素（代码里的逻辑坐标 = 原图像素 ÷ 6，绘制时放大 2 倍）。厨房、小馆、地图仍是 2 个 CSS 像素 = 1 个美术像素。画布宽度跟着屏幕走；界面图标统一 2 倍，只有完成菜品、金币奖励这类强调时刻用 4 倍；边框 2px。
- **农场上叠加的东西**：底图和叠加的东西画在同一张画布上，拖动时一起移动；画布按手机的设备像素比渲染，3 倍屏上原画 1:1 显示、位置吸附到整像素，不糊不闪。开垦的地块直接取自开垦版底图；豆豆和鸡窝直接画；作物和母鸡先用 Scale2x 放大 2 倍，再自动加受光/背光、深色勾边，眼睛和果实补白色反光。为了和原画角色比例一致，作物和母鸡再放大 1.25 倍，豆豆 1.5 倍。描边一律用色卡里的暖深棕，不用纯黑。
- **色板**：只用色卡 v2 `art/palette/`（16 组 × 8 级 = 128 色，统一明度阶 + 色相偏移，脚本里的 `PALETTE`）。代码里按名字取色的 `PAL` 指向色卡里的某一级；所有画笔函数把颜色吸附到色卡，高清叠加层最后也整张吸附一遍；描边统一用「暖灰·墨」第 1 级；界面 CSS 变量对应色卡里的界面用色（对比度都 ≥ 4.5:1）。农场底图用 `tools/grade_bg.py` 整体调亮。规矩和用法见 `ART.md`。
- **透视与比例**：农场跟着底图的透视走，地块就是图里的草格；厨房和小馆是 2:1 等距视角。作物 28×32、豆豆连葱约 19px（逻辑像素）。光从左上来，角色、作物、道具都有接地阴影。
- **白天模式**：现在农场、厨房、小馆一直是白天。**夜晚模式在开发中**，还没定怎么做（`todPhase()` 固定返回 `day`，原来的夜色代码先留着不用）。
- **字体**：中文用 12px 像素字体（18px = 1.5 倍、24px = 2 倍），英文和数字用 Jersey 10（20 / 30 / 40px），两种字体都内联在页面里。
- **触控**：所有按钮至少 44×44px；主要操作放在底部拇指区，「跳过」「以后再说」这类次要操作用文字链接。

- 改了中文：运行 `python3 game/tools/build_fonts.py`（需要 `pip install fonttools brotli`），新出现的字才会有像素字形。
- 改了英文句子：按 `game/tools/gen_voice.py` 开头的步骤重新生成 `voice.js`，否则新句子会退回用浏览器自带朗读。
- 改了 `sw.js` 缓存的文件：把 `sw.js` 里的版本号 `V` 加一，已经装过的手机才会更新。
