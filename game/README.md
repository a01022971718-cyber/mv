# 豆豆的田园厨房（像素风手机游戏 demo）

种菜、用英语口语做菜，再用英语接待客人。网页游戏，不用安装，第一次联网打开后可以离线玩。

## 玩法循环

1. **农场**：16 块地，一开始开好 6 块，其余升级后花金币开垦。点空地选一次种子，之后点别的空地就连着种同一种（底部有播种条，点「完成」结束）；种子沿弧线落进土里，小苗弹出来。熟了头顶出现「⭐可收」，收获时果实弹起、冒星星、飞进仓库，收完地直接变回空土。点地块还能捉虫、除草、浇水。地块头顶的气泡告诉你该做什么。虫子、杂草和缺水都会拖慢生长。母鸡每 75 秒下一个蛋。收获时会弹出一句英文让你跟读，说得好可以多拿 1～2 个作物。
2. **厨房**：8 道菜，按等级解锁。每一步都是一句英文做法（Wash the lettuce. / Crack two eggs into a bowl. …），说完后豆豆会把这一步做出来。每步平均星级决定这道菜是几星，星级越高售价越高。
3. **小馆**：小动物客人用英语点菜、问价，你要用英语回答和报价（价格数字每次不同）。两句都说到三星还有小费。
4. **词本**：食材、动作动词、做菜句子、待客句子都收在这里，带音标和每条的最佳成绩。「快速练习 ×5」会优先抽你说得最差的几条。

## 两种玩法

设置最上面可以切换：
- **学习模式**（默认）：收菜要跟读，做菜每一步、上菜每一句都要说出来，系统打分；星级决定菜价和小费。
- **游戏模式**：收菜、做菜、上菜都不用开口。英文照样显示、照样读给你听；做菜点「做这一步」就做（算两星），上菜点「下一句」往下走。想练的时候点「开口说」，说好了多拿星星和小费。离线识别的开通卡和评分设置在这个模式下收起来。

## 我们自己的记忆点

- **会说英语的蔬菜**：8 种作物各有独特的轮廓和主色（圆红番茄、尖橙胡萝卜、疙瘩土豆、紫洋葱、高个玉米、褶边生菜、心形草莓、扁圆南瓜）。成熟后长出小脸，表情来自它的英文收获句：番茄 *red and ripe* 会脸红，洋葱 *Onions make me cry!* 会流泪，土豆 *Dig up the potatoes* 埋在土里打瞌睡，南瓜 *What a big pumpkin!* 一脸得意。成熟的菜还会轮流冒出气泡喊自己的英文名。
- **作者原画的两种作物**：精灵芽 *sprout*（Lv2）和蓝铃花 *bluebell*（Lv4），种子店能买，长大和成熟时直接显示作者画的图。收获句：*The sprout is smiling at me!* / *Listen! The bluebell is singing.*
- **点哪儿学哪儿**：农场里的房子、稻草人、喷泉、信箱（放了装扮时）、远处的小屋 cottage、小山坡 hill、小路 path、灌木丛 bush、云 cloud、海、山、栅栏、花、母鸡、窝都能点，点一下弹出英文名牌并读出来。左上角「标签」按钮一次显示所有名牌。这些词也收在词本的「场景」分类里。
- **住在作物里的四只精灵**：Sprig 小芽、Bud 苞苞、Sunny 阳阳住在精灵芽里，Swirl 旋旋住在蓝铃花里。还没熟的精灵芽、蓝铃花点一下，精灵会用自己的声音说一句英文（下面跟中文），每次换一句；12 句台词也收在词本的「精灵」分类里，可以跟读练习。
- **农场画面**：底图是作者交的干净底图（`art/src/farm-clean-ai.jpg`，去掉了稻草人、房子、喷泉、信箱），`tools/bg_prepare.py` 补好右边接缝、拼出「没开垦」版（草格菜地取自原画）、整体提亮，得到 `art/farm.webp`（没开垦）和 `art/farm-open.webp`（开垦版里菜地那一块）。哪块地开垦了，就从开垦版里按这块地的形状裁出来盖上去。稻草人、房子、喷泉、信箱都是装扮，单独画在上面。

图比手机屏幕宽，在农场上左右拖动就能看到右边的蛋糕屋、喷泉和蘑菇信箱；还能往哪边拖，画面边上就有小箭头提示。豆豆在菜地下面的沙土路上走，母鸡和鸡窝在菜地左下的草地上（这两样还是代码画的，等美术素材，见 `ART.md`）。

## 装扮

农场左上角的「装扮」按钮打开装扮窗口。稻草人、房子、喷泉、信箱和每种作物各有一个装扮位，点一下就换上，存档会记住。
- **默认**：稻草人是圣诞稻草人，房子是万圣节树屋；喷泉、信箱默认空着，等上传。场景物件都可以选「不放」。
- **自带的装扮**：圣诞稻草人、万圣节树屋、南瓜精灵（南瓜长大和成熟时的样子）。
- **上传自己画的图**：在装扮位后面点「＋ 上传」，从手机里选一张图。游戏会自动处理：白底图去背景、去掉 AI 抠图留下的半透明淡雾、裁掉四周空白、按装扮位的大小等比缩小、按色卡校色。上传的装扮存在这台手机的浏览器里（IndexedDB），断网也能用，换手机要重新上传；点缩略图右上角的 × 删除。
- **调整位置和大小**：装扮窗口里点「调整位置和大小」，回到农场用手指拖动物件，下面的按钮放大、缩小、还原，点「完成」记住（每个装扮分开记）。点物件时按图里不透明的地方判断，透明的空隙点下去算点到后面的东西。

加新的装扮位：在 `index.html` 的 `SKIN_SLOTS` 里加一行（`anchor` 是脚底中点、`box` 是最大宽高，都按农场原画的像素；`def` 是默认装扮）。自带装扮放在 `art/skins/`（用 `tools/skin_prep.py` 处理），在 `SKINS` 里登记。规格见 `ART.md`。

## 地图

状态栏的地图按钮打开一张像素小岛地图。农场、厨房、小馆、单词屋可以直接前往；集市、森林、学校、码头先标「敬请期待」。地点名都是英文，点一下会读出来。

加新玩法时：在 `index.html` 的 `MAP_SPOTS` 里加一行（`view` 指向新页面，或先写 `soon: true`），在 `MAP_ICON` 里画一个 16×16 的图标，需要的话在 `MAP_ROADS` 里连一条路。

## 示范发音

- 所有句子和单词都用开源神经网络语音 [Kokoro](https://huggingface.co/hexgrad/Kokoro-82M) 预先合成成录音，打包在 `voice.js` 里（668 条，标准美式发音），不依赖手机自带的朗读，也不需要联网。
- 每句话有两种播放：**原速**（自然语速）和**逐词**（一个词一个词读，正在读的词会高亮）。句子里的任何一个词也可以直接点着听。
- 示范句用同一个女声（af_heart）。五位客人各有自己的声音，听力练习时能听到不同的人说话。
- 生成后用 Vosk 把每条句子反向听写了一遍，整体词错误率 2.6%，剩下的错误基本是识别模型自己的同音混淆（pour/poor、coins/kinds）。检查中发现 Kokoro 把做菜用的 tear（撕，/ter/）读成了 tear（眼泪，/tɪr/），已经用音标强制改正。单读的 a 用弱读 /ə/，和句子里一致。

## 离线口语识别

- 用 [Vosk](https://alphacephei.com/vosk/) 英文小模型，在浏览器里以 WebAssembly 运行（`vendor/vosk.js`），录音不出手机。
- 第一次打开时，农场页有一张「开启离线口语评分」卡片：点「开启」会请求麦克风权限并下载约 40MB 的模型，显示真实的下载百分比。模型下载后由识别库存进浏览器的 IndexedDB，之后断网也能用。也可以以后在口语卡或设置里再开。
- 录音时麦克风键里有实时音量条；说完停顿约 1.5 秒自动结束，显示「识别中…」。说完可以点「听我的」回放自己的录音，和示范对比。
- 两种识别模式（设置里切换）：
  - **宽松**（默认）：只在游戏里出现过的句子和单词里找，听不清的词记作「？」。口音重一些也能认出来。
  - **严格**：不限词表，发音不准的词会被认成别的词，更能暴露发音问题。
- 打分：识别结果和目标句逐词比对，忽略大小写、标点、缩写（it's = it is）和阿拉伯数字（32 = thirty two），单复数算接近，识别置信度低的词也只算接近。每个词标绿、黄或红，85 分以上三星，60 分以上两星。
- 说明：这是「说的词对不对、清不清楚」的检查，不是逐个音素的专业发音评测。
- 拿不到麦克风时（比如在 claude.ai 里打开），自动改成「听 → 跟读 → 自评」。

## 在手机上打开

麦克风需要 HTTPS 页面：

- **直接打开**：`https://raw.githack.com/a01022971718-cyber/mv/ccr-17470247-hlo7zp/game/index.html`
  （raw.githack 是第三方服务，把这个公开仓库的文件按网页转发出来。）
- **GitHub Pages**：仓库 Settings → Pages → 选这个分支，然后打开 `…/game/index.html`。如果想连模型也自己托管，把 `vosk-model-small-en-us-0.15.tar.gz` 放到 `game/vosk/` 下再提交（这个目录默认被 .gitignore 忽略）。

打开后在浏览器菜单里点「添加到主屏幕」/「安装应用」，就能像 App 一样全屏打开。离线用的前提是：联网打开过一次（缓存游戏和发音包），并在游戏里下载过一次识别模型。

### 更新和存档

- **一个地址 = 一份游戏 + 一份存档**。进度存在那个地址的浏览器存储里：同一个地址更新后进度保留；换了地址（比如 claude.ai 里的版本、另一个托管地址）就是另一份，进度不通用。claude.ai 上的 Artifact 版本是单独的一份（进度同步到 Claude 账号），不是手机上那个图标的更新渠道。
- **自动检查更新**：联网打开时，游戏去 GitHub 看最新版本号（`version.json`），比自己新就弹窗「有新版本」，点「现在更新」只换游戏本身，进度、金币、单词成绩都保留。设置 →「版本」里也能手动「检查更新」。
- **raw.githack 的缓存**：它的分支地址有时会把旧文件缓存好几个小时，所以在 githack 上更新时，游戏会跳到最新提交的固定地址（`raw.githack.com/…/<提交号>/game/index.html`，和图标是同一个网站，进度共用）。GitHub Pages 没有这个问题，更适合长期当 App 用。
- **存档码**：设置 →「复制存档码」把整份进度变成一串 `DOUDOU1.` 开头的文字；到另一个地址或另一台手机，设置 →「粘贴存档码」就能把进度搬过去。
- **发布新版本时**：想让已经装好的手机弹出「有新版本」，就把 `index.html` 里的 `BUILD` 加一、`version.json` 里的 `build` 同步改（小修小补可以不加，下次打开会悄悄换上）；动了缓存的文件还要把 `sw.js` 的 `V` 加一。玩家点了「以后再说」，这一版就不再自动弹，设置里仍能手动更新。
- **安装成 App**：清单文件叫 `manifest.json`。raw.githack 会把 `.webmanifest` 和图片重定向到 raw.githubusercontent（另一个网站），浏览器会因此提示「无法安装此应用」；`.json` 它会直接转发，没有这个问题。githack 的固定提交地址（用来更新的那个）故意不提供安装，免得装出第二个图标。

## 美术与界面规范

- **引擎**：农场画面用 [Phaser](https://phaser.io) 3.90（Canvas 渲染）画：底图、开垦的地、装扮物件、作物、角色、特效、气泡名牌都是场景对象，按脚底位置排前后；拖动画面就是移动镜头。游戏逻辑、点击判定、厨房、小馆、地图还是原来的代码，以后一页页搬进引擎。
- **像素单位**：农场底图按 384 CSS 像素高显示（原图 3 像素 = 1 CSS 像素，3 倍屏手机上正好一一对应）；叠在上面的画布是 1 个美术像素 = 1 个 CSS 像素（代码里的逻辑坐标 = 原图像素 ÷ 6，绘制时放大 2 倍）。厨房、小馆、地图仍是 2 个 CSS 像素 = 1 个美术像素。画布宽度跟着屏幕走；界面图标统一 2 倍，只有完成菜品、金币奖励这类强调时刻用 4 倍；边框 2px。
- **农场上叠加的东西**：底图和叠加的东西画在同一张画布上，拖动时一起移动；画布按手机的设备像素比渲染，3 倍屏上原画 1:1 显示、位置吸附到整像素，不糊不闪。开垦的地块直接取自开垦版底图；豆豆和鸡窝直接画；作物和母鸡先用 Scale2x 放大 2 倍，再自动加受光/背光、深色勾边，眼睛和果实补白色反光。为了和原画角色比例一致，作物和母鸡再放大 1.25 倍，豆豆 1.5 倍。描边一律用色卡里的暖深棕，不用纯黑。
- **色板**：只用色卡 v2 `art/palette/`（16 组 × 8 级 = 128 色，统一明度阶 + 色相偏移，脚本里的 `PALETTE`）。代码里按名字取色的 `PAL` 指向色卡里的某一级；所有画笔函数把颜色吸附到色卡，高清叠加层最后也整张吸附一遍；描边统一用「暖灰·墨」第 1 级；界面 CSS 变量对应色卡里的界面用色（对比度都 ≥ 4.5:1）。农场底图用 `tools/grade_bg.py` 整体调亮。规矩和用法见 `ART.md`。
- **透视与比例**：农场跟着底图的透视走，地块就是图里的草格；厨房和小馆是 2:1 等距视角。作物 28×32、豆豆连葱约 19px（逻辑像素）。光从左上来，角色、作物、道具都有接地阴影。
- **夜晚**：农场跟着手机的真实时间变化。夜色压暗整张底图和作物；豆豆只略微变暗，状态气泡不受影响，蛋糕屋的门口和小窗会亮灯。
- **字体**：中文用 12px 像素字体（18px = 1.5 倍、24px = 2 倍），英文和数字用 Jersey 10（20 / 30 / 40px），两种字体都内联在页面里。
- **触控**：所有按钮至少 44×44px；主要操作放在底部拇指区，「跳过」「以后再说」这类次要操作用文字链接。

## 改内容

数据都在 `index.html` 的「游戏数据」一节：`CROPS`（作物、生长秒数、收获句；带 `art` 的用 `art/` 里的图）、`RECIPES`（菜谱和每一步的英文）、`T_ORDER` / `T_REPLY` / `T_ASK` / `T_PRICE` / `T_THANKS`（小馆对话模板）。新增一步做菜时，`act` 决定厨房里播放哪个动画（wash / cut / peel / tear / scoop / mix / crack / mash / heat / fry / boil / blend / pour / season / bake / serve）。

换农场底图：美术按 `ART.md` 交两张同尺寸的图（没开垦 / 全开垦），运行 `python3 game/tools/farm_plots.py 没开垦.png 全开垦.png game/art`，把打印出来的 `c`（中心）和 `q`（四个角）贴进 `PLOT_IMG`、`PLOT_QUAD`；再按新图量 `SPOTS`（可点物件）、`HOUSE_GLOW`（夜里亮灯）、`NEST`、`HEN`、豆豆的 `pathAt`。图的宽高变了还要改 `FARM.world` 和 `FARM.h`。

改了内容之后：
- 改了中文：运行 `python3 game/tools/build_fonts.py`（需要 `pip install fonttools brotli`），新出现的字才会有像素字形。
- 改了英文句子：按 `game/tools/gen_voice.py` 开头的步骤重新生成 `voice.js`，否则新句子会退回用浏览器自带朗读。
- 改了 `sw.js` 缓存的文件：把 `sw.js` 里的版本号 `V` 加一，已经装过的手机才会更新。
