# 加一个玩法模板

先判断：用户要的能不能用现有模板做？
- 「放进去、等、收获」→ 养成（grow）。牧场、果园、养鱼、温室都是。
- 「碰运气抓一个」→ 钓鱼/采集（catch）。池塘、捉虫、挖宝、采蘑菇都是。
- 「看看、点点、听英文」→ 地图里的「场景」+ 可点的东西。
能做就教用户在工具箱里做，**不要写代码**。做不出来才加模板。

## 模板长什么样（`index.html` 的「工具箱」一节）

```js
MOD_TPL.<id> = {
  zh: '名字', desc: '一句话说明这是什么玩法、能做成什么',
  fields: [['字段', '中文说明（括号里是提示）', 默认值], ...],   // 每样东西除了图片/中文/英文以外要填的数字
  line: true,                                                   // 要不要「一句话」（收获时说的英文）
  starter: () => ({ ...新玩法的默认数据, items: [...] }),        // 开箱就能玩的样子（图片可以用代码画的小图）
};
```
玩法数据在 `S.cfg.mods[id]`（`tpl, name, bg, items, fx, bgm` + 模板自己的），进度在 `S.cfg.modState[id]`（`modSt(id)`）。

还要改的地方：
1. `mpItems()`：这种玩法画面上画什么（按 `m.tpl` 分支）。每秒刷新时别整块重画（看养成怎么用 `MP.sig`）。
2. 点击：`bindModInput()` 的 click 分支，调用你的 `<id>Tap()`；底栏按钮在 `mpFoot()`。
3. 收获/成功时统一用：`fxBurst(MP.fx, x, y, m.fx)`、`SFX.harvest()`/`SFX.coin()`、`say(英文)`、`gainCoins()`、`gainXP()`、`modSt(id).got[东西]++`（图鉴自动有）。
4. `mpDraw()` 的提示文字；编辑模式要调的东西放进 `mpFoot()` 的编辑分支。
5. 英文会自动进语音包和词本（`itemForm` 已经调用 `addMyWord`）。

## 测试

在 `game/tests/toolkit.js` 里照「牧场」「池塘」加一段：用工具箱新建 → 进去玩一次 → 检查金币、图鉴、特效、重新打开还在。然后 `bash game/tests/run.sh` 全部通过，再用 `doudou-release` 发布。
