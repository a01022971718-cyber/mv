# 加课 / 改课

内容只写文案，**不用做语音**（手机上的语音包会生成），**不用改识别词表**（`grammarJSON()` 自动包含全部课程）。

```js
U(等级, 'id', '中文课名', 'English Title', '单词=中文|单词=中文|…（8 个左右）', '句子=中文|句子=中文|…（4–5 句）'),
```
- 等级 1：单个名词、颜色、数字、3–5 个词的短句；2：日常短句；3：问答、常用动词；4：形容词、过去时、10 个词左右的句子；5：将来时、观点、连贯的几句话。
- 句子里的撇号写 `\'`；一句话里不要有 `|` 和 `=`。
- 和游戏里的东西挂钩更好记（农场、做菜、小馆、地图、玩法）。

考试：`examQuestions(lv)` 出 12 题（5 听、4 看中文选、3 开口说；没麦克风时 0 说），`PASS` 是及格分（80）。改了要跑 `game/tests/learn.js`。
